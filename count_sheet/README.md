# ใบนับสต๊อก P&G — โมดูลสำหรับ BL Tools

## ติดตั้ง (ทำครั้งเดียว)
1. คัดลอกโฟลเดอร์ `count_sheet` ทั้งโฟลเดอร์ไปไว้ข้างไฟล์ `app.py`
2. เปิด `app.py` เพิ่ม 2 บรรทัดนี้ หลังบรรทัดที่มี `app = Flask(__name__)`

       from count_sheet import bp as count_sheet_bp
       app.register_blueprint(count_sheet_bp)

3. เปิด `requirements.txt` ตรวจว่ามีบรรทัด `openpyxl` (ถ้าไม่มี ให้เพิ่ม)
4. เพิ่มลิงก์ในหน้าแรกของ BL Tools ไปที่ `/count-sheet/`
5. Commit + push ขึ้น GitHub → Render deploy เอง

## ขั้นตอนการใช้งาน (หน้า /count-sheet/) — ทำเป็นรายวัน
1. สร้างใบนับครั้งที่ 1 — อัปโหลด Stock MC + Stock FO (ยอดตั้งต้น) เลือก Day
2. นับแล้วกรอกคอลัมน์ "ยอดตรวจนับ" (ไม่มีของ = 0, ห้ามแทรก/ลบ/สลับแถว/เปลี่ยนชื่อชีต)
3. อัปโหลดไฟล์ที่กรอกแล้ว ระบบเทียบยอดนับกับยอดตั้งต้น "รายบรรทัด"
   - บรรทัดที่ไม่ตรง → ใบนับครั้งที่ 2 (ฟอร์มเดิม เฉพาะบรรทัดที่ Diff, หัวกระดาษ ครั้งที่ตรวจนับ = 2)
   - ครั้งที่ 2 ยังไม่ตรง → ใบนับครั้งที่ 3
   - MC / FO แยกกันได้: ชีตที่ยังไม่กรอกเลยจะติดไปในไฟล์ใหม่ให้กรอกทีหลัง
   - ไม่เหลือใบนับค้าง → สรุปผลการนับประจำวัน (ฉบับสุดท้าย)
4. ทุกไฟล์ที่ได้หลังอัปโหลดมี "สรุปผลการนับ" (ชนสต็อก MC+FO ต่อ SKU) และ "บรรทัดที่ Diff" (ยอดแต่ละครั้งราย Location)

ประวัติทุกครั้งที่นับเก็บในชีตซ่อน _meta และ _data ภายในไฟล์ — ห้ามลบ

## โครงสร้าง
- `__init__.py` — หน้าเว็บ /count-sheet/ (รับไฟล์, ส่งไฟล์ใบนับกลับ)
- `generator.py` — ตัวสร้างใบนับ (ค่าหัวใบนับ เช่น SELLER / ZONE แก้ได้ด้านบนไฟล์)
- `data/form_template.xlsx` — ฟอร์มใบนับต้นแบบ (14 แถว/หน้า + ช่องลายเซ็น)
- `data/plan.xlsx` — แผนนับ 30 วัน (day, round, sku) ดึงจากชีต ชนสต็อก_SKU ของไฟล์ Cycle ต.ค. 2026 — คอลัมน์ sku ตั้งเป็น Text ไว้แล้ว เปิดแก้ใน Excel ได้
- `templates/count_sheet/index.html` — หน้าเว็บ

## เปลี่ยนรอบแผน
- ใช้ครั้งคราว: บนหน้าเว็บกด "ใช้แผนนับจากไฟล์ Cycle อื่น" แล้วแนบไฟล์ Cycle ใหม่
- ใช้ถาวร: แทนที่ `data/plan.xlsx` ด้วยแผนใหม่ (หัวคอลัมน์ day | round | sku เหมือนเดิม) แล้ว push

## ข้อควรรู้ก่อนใช้งาน
- ยอดในระบบ = Stock ตั้งต้นที่อัปโหลดตอนสร้างครั้งที่ 1 ใช้ตลอดทั้ง 3 ครั้ง (ถ้ามีหยิบ/รับของระหว่างนับ จะเห็นเป็น Diff)
- อัปโหลด "ไฟล์ล่าสุด" เสมอ ถ้าอัปโหลดไฟล์เก่าซ้ำ ระบบจะคำนวณใหม่จากไฟล์นั้น (ได้ผลแยกออกไปอีกชุด)
- ระบบตรวจทุกแถวว่า Location / รหัสสินค้า / LPN ตรงกับที่ออกไป ถ้าเรียงหรือสลับแถว จะแจ้ง error
- SKU ที่ยอดรวม MC+FO ตรง แต่บางบรรทัดไม่ตรงหลังนับ 3 ครั้ง จะขึ้นสถานะ "ยอดรวมตรง แต่ Location ไม่ตรง"

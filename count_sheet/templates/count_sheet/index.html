ใบตรวจนับสต๊อก P&G

ออกใบนับเป็นรายวัน กรอกยอดที่นับได้ แล้วเทียบกับยอดตั้งต้น บรรทัดที่ Diff จะออกใบนับครั้งที่ 2 และ 3 ให้นับซ้ำ

  1. สร้างใบนับครั้งที่ 1 จาก Stock ตั้งต้น
  2. นับและกรอกยอดตรวจนับลงในไฟล์
  3. อัปโหลดผลได้ใบนับครั้งถัดไปเฉพาะบรรทัดที่ Diff
  4. สรุปผลเมื่อตรงหมดหรือนับครบ 3 ครั้ง

2อัปโหลดใบนับที่กรอกยอดแล้ว

กรอกตัวเลขในคอลัมน์ "ยอดตรวจนับ" ของไฟล์ที่ดาวน์โหลดจากหน้านี้ แล้วอัปโหลดกลับ

  • บรรทัดที่ยอดนับไม่ตรงกับยอดตั้งต้น จะออกเป็นใบนับครั้งที่ 2 (ฟอร์มเดิม) เฉพาะบรรทัดนั้น ครั้งที่ 2 ยังไม่ตรงก็ออกครั้งที่ 3
  • MC กับ FO แยกกันได้ นับโซนไหนเสร็จก่อนก็กรอกแล้วอัปโหลดได้เลย ชีตที่ยังไม่กรอกจะติดไปในไฟล์ใหม่
  • ไม่มีใบนับค้างแล้ว ได้รายงานสรุปผลการนับประจำวันฉบับสุดท้าย
  • ไม่มีของที่ Location ไหน ให้กรอก 0 ห้ามเว้นว่าง และห้ามแทรก ลบ หรือสลับแถว
